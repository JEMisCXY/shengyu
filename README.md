# 模拟歌手：声屿

打开网站：https://jemiscxy.github.io/shengyu/

支持创建歌手、编歌单、本地规则编排、舞台布置、单机演出和票根；支持导入自己的音频与歌词、开麦演唱、灯光响应、自动录制歌声与伴奏、重唱和保存 WAV 到本地。

通过 HTTPS 打开并允许麦克风权限，建议使用电脑 Chrome 或 Edge。暂停和段间休息不录入，重唱替换本首录音。关闭或刷新页面前，请先保存录音。音频与个人资料仅存于访问者浏览器，不上传，不自动跨设备共享。本仓库不分发音频。

当前没有后台，好友房间同步、同步应援、联机语音与在线模型编排暂未开放。本地规则编排可正常使用。按 F3 可查看舞台实时性能。
